# RAILPOOL AI 화면별 시각 개편 요약

## 내 운송
- 배경은 옅은 회색, 운송 단위는 흰 카드와 1px 보더로 분리했습니다.
- 화면 제목과 카드 제목을 20px/17px 위계로 정리하고 숫자는 tabular 정렬했습니다.
- 새 운송 요청만 Primary로 강조하고 필터는 38px Chip으로 통일했습니다.

## 새 운송 요청
- 기존 3단계 입력 순서와 음성·직접·문서 플로우를 그대로 유지했습니다.
- 모든 입력 카드에 20px 패딩과 16px radius를 적용해 현장 스캔성을 높였습니다.
- 선택값은 Blue tint Chip, 이전/다음은 Secondary 1 : Primary 1.5로 정리했습니다.

## 운송 제안
- 추천 사유를 17px SemiBold로 올려 비용 숫자보다 먼저 읽히게 했습니다.
- 확인 완료/예상값 배지를 파랑 tint와 주황 outline 두 규격으로 제한했습니다.
- 거절은 Secondary, 적용은 Primary, 상세 비교는 Tertiary로 재분류했습니다.

## 제안 비교
- 기존 비교 항목과 정보 순서를 유지하면서 카드·표의 그림자를 제거했습니다.
- 핵심 판단 문장은 17px SemiBold, 비용과 시간은 tabular 숫자로 정리했습니다.
- 하단 액션은 좌 Secondary, 우 Primary의 1 : 1.5 비율로 고정했습니다.

## 함께 보내기
- 달성률, 참여사, 비용 카드를 각각 하나의 의사결정 단위로 분명히 구획했습니다.
- 긍정 정보는 초록, 확정 정보는 파랑으로 제한하고 장식성 색을 제거했습니다.
- 조건 수정/검토 요청/취소를 Secondary/Primary/Tertiary로 명확히 구분했습니다.

## 변동 알림
- 실시간 상태와 영향 정보를 흰 카드 및 1px 보더로 안정적으로 정돈했습니다.
- 주의 정보는 주황, 확정 정보는 파랑으로 제한해 빠르게 구분되도록 했습니다.
- 복구 액션은 Secondary 1 : Primary 1.5 구조와 52px 높이로 통일했습니다.

## 코레일 검토 요청
- 검토 항목의 기존 접기/펼치기 구조와 제출 플로우는 유지했습니다.
- 확인 상태 배지, 본문, 금액의 위계를 12/15/17px 체계로 정돈했습니다.
- PDF 저장은 Secondary, 검토 요청은 유일한 Primary로 배치했습니다.
