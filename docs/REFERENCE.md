# 화면 기준

기준일: 2026-08-13
기준 환경: macOS 아이폰 미러링에 표시된 코레일+ 앱
기준 캡처 크기: 318 × 701

확인한 화면:

- 홈
- 이동·편의
- 여행
- 나의 티켓
- 전체메뉴
- 혜택·정기권

개인 계정 데이터가 표시된 전체메뉴 원본 캡처는 프로젝트에 복사하지 않았습니다. 구현에는 동일한 레이아웃과 샘플 회원값만 사용했습니다.

시각 기준의 우선순위는 다음과 같습니다.

1. 실제 앱 캡처
2. `src/design-system/tokens.css`
3. `#/design-system` 컴포넌트 쇼케이스
4. 화면별 CSS
