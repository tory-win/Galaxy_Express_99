# 코레일+ 디자인 시스템

## 1. 원칙

- 배경은 흰색과 아주 옅은 보랏빛 회색(`#F8F7FC`)을 명확히 분리합니다.
- 주요 행동과 선택 상태는 코레일 블루(`#1B72F4`) 하나로 통일합니다.
- 정보 밀도는 높지만 여백을 4px 단위로 관리해 답답하지 않게 유지합니다.
- 카드 남용은 피하고, 실제 코레일+처럼 기능 묶음에만 흰 카드와 낮은 그림자를 사용합니다.
- 하단 내비게이션, 헤더, 탭은 모든 화면에서 같은 높이와 선택 규칙을 유지합니다.
- 새 기능의 텍스트, 버튼, 탭, 입력은 반드시 코드 네이티브로 구현합니다.

## 2. 토큰

토큰의 단일 기준은 `src/design-system/tokens.css`입니다.

### 색상

| 토큰 | 값 | 용도 |
|---|---:|---|
| `--kr-color-brand` | `#1B72F4` | 선택 상태, 주요 버튼, 강조 텍스트 |
| `--kr-color-brand-soft` | `#EEF5FF` | 블루 보조 배경 |
| `--kr-color-ink` | `#202127` | 제목과 핵심 본문 |
| `--kr-color-body` | `#3A3D45` | 일반 본문 |
| `--kr-color-muted` | `#8B8E97` | 설명, 비활성 탭 |
| `--kr-color-line` | `#E6E7EB` | 구분선 |
| `--kr-color-canvas` | `#F8F7FC` | 페이지 캔버스 |
| `--kr-color-surface` | `#FFFFFF` | 카드와 헤더 |

### 타이포

- 기본 글꼴: Apple SD Gothic Neo를 포함한 시스템 한글 산세리프 스택
- 크기: 10 / 11 / 12 / 13 / 14 / 16 / 18 / 20px
- 가중치: 400 / 500 / 650 / 750
- 한글 제목은 약한 음수 자간을 사용해 실제 앱의 조밀한 인상을 유지합니다.

### 간격과 형태

- 간격: 4 / 8 / 12 / 16 / 20 / 24 / 32px
- 입력 컨트롤 곡률: 8px
- 카드 곡률: 11px
- 시트 곡률: 24px
- 카드 그림자: `0 5px 16px rgba(35, 42, 62, 0.075)`

## 3. 공개 컴포넌트

`src/design-system/index.js`에서 아래 컴포넌트를 제공합니다.

| 컴포넌트 | 목적 |
|---|---|
| `StatusBar` | 기준 iOS 상태 바 표현 |
| `AppHeader` / `AssetButton` | 제목·로고·뒤로가기·헤더 행동 |
| `BottomNav` | 5개 메인 탭과 선택 상태 |
| `Surface` | 공통 흰색 카드 컨테이너 |
| `ServiceTile` | 아이콘 + 짧은 서비스 라벨 |
| `SegmentTabs` | 상단 언더라인 탭 |
| `FilterChip` | 지역·티켓 유형 필터 |
| `SearchField` | 블루 테두리 검색 입력 |
| `MenuRow` | 전체메뉴 목록 행 |
| `ProductCard` | 정기권 등 혜택 상품 카드 |

## 4. 새 화면 제작 규칙

1. `StatusBar`와 `AppHeader`로 상단 구조를 고정합니다.
2. 화면이 메인 탭이면 `BottomNav`를 그대로 사용합니다.
3. 기존 패턴으로 표현 가능한 UI는 새 컴포넌트를 만들지 않고 조합합니다.
4. 새 패턴이 반복될 때만 `src/design-system/components`에 추가하고 `index.js`에서 export합니다.
5. 색상, 곡률, 그림자는 반드시 `--kr-*` 토큰을 사용합니다.
6. 318 × 701 기준으로 먼저 맞춘 뒤, 앱 셸의 비례 확대를 통해 다른 모바일 크기에 대응합니다.
7. 계정·티켓·위치 데이터는 화면 컴포넌트에 하드코딩하지 않고 `src/data` 또는 API 어댑터로 분리합니다.

## 5. 화면 QA 체크리스트

- 헤더 시작선, 콘텐츠 좌우 여백 23px, 하단 탭 높이가 기존 화면과 일치하는가
- 선택 상태가 코레일 블루 하나로 일관되는가
- 카드 반경과 그림자가 토큰값을 사용하는가
- 비활성 텍스트가 본문보다 충분히 약한가
- 라벨이 두 줄로 깨지거나 버튼 바깥으로 넘치지 않는가
- 키보드 탐색, `aria-label`, `aria-current`, 탭 역할이 유지되는가
- 318 × 701에서 핵심 콘텐츠가 잘리지 않는가

브라우저에서 `#/design-system`을 열면 토큰과 컴포넌트를 실시간으로 조작하며 확인할 수 있습니다.
